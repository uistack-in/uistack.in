# 🎨 Uistack — Free UI Components Library

**Copy-paste ready UI components built with HTML, CSS, Bootstrap & Tailwind CSS**

🌐 **Website:** [uistack.in](https://uistack.in)

---

## ✨ What is Uistack?

Uistack is a **free UI component library** for developers and designers who want beautiful, ready-to-use components without starting from scratch.

Just **copy, paste, and ship** — no installation, no build tools needed.

---

## 🚀 Features

- ✅ **Copy-paste ready** — No setup required
- 🎨 **Pure HTML & CSS** components
- 💠 **Bootstrap** compatible components
- 🌬️ **Tailwind CSS** components
- 📱 **Fully responsive** on all screen sizes
- 🌗 **Dark mode** support
- 🆓 **100% Free** — no login required
- 🇮🇳 Built with ❤️ in India

## 🛠️ How to Use

1. Go to **[uistack.in](https://uistack.in)**
2. Browse components
3. Click **Copy Code**
4. Paste into your project

No npm install. No configuration. No login.
